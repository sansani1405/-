# ระบบเช็คชื่อเข้าเรียนด้วย QR Code (ต้นแบบ)

เว็บไซต์ Flask + SQLite สำหรับทดลองระบบเช็คชื่อ QR บนมือถือและคอมพิวเตอร์

## คุณสมบัติที่มีในต้นแบบ
- เข้าสู่ระบบครูและนักเรียนด้วยชื่อผู้ใช้/เลขประจำตัวนักเรียนและรหัสผ่าน
- ครูสร้างรายวิชา สร้างรอบเช็คชื่อ ระบุหลายห้อง และตั้งเวลาเริ่ม/เริ่มนับสาย/ปิดรับ
- QR Code ที่มี token ลงลายเซ็น เปลี่ยนทุก 5 นาที และ token รอบก่อนหน้าหมดอายุ
- นักเรียนเช็คชื่อได้เมื่อมีบัญชีและลงทะเบียนในรายวิชานั้น และเช็คซ้ำไม่ได้
- นักเรียนดูประวัติการเช็คชื่อของตนเอง
- ครูดูรายงาน เปลี่ยนสถานะ/เช็คชื่อแทน พร้อมบันทึก audit log
- นำเข้ารายชื่อนักเรียนจาก Excel (.xlsx) และดาวน์โหลดไฟล์ตัวอย่าง
- ส่งออกผลเช็คชื่อเป็น Excel

## วิธีติดตั้ง
ต้องมี Python 3.10 หรือใหม่กว่า

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## ตั้งค่าก่อนเริ่ม
ตั้งค่าคีย์ลับที่ยาวและไม่ซ้ำกัน และ URL ที่นักเรียนเปิดถึงได้

Windows PowerShell:
```powershell
$env:SECRET_KEY="ใส่ค่าสุ่มที่ยาวและไม่ซ้ำ"
$env:QR_SECRET="ใส่ค่าสุ่มอีกชุดหนึ่ง"
$env:PUBLIC_BASE_URL="http://IP-หรือโดเมนของเซิร์ฟเวอร์:5000"
python app.py
```

macOS/Linux:
```bash
export SECRET_KEY='ใส่ค่าสุ่มที่ยาวและไม่ซ้ำ'
export QR_SECRET='ใส่ค่าสุ่มอีกชุดหนึ่ง'
export PUBLIC_BASE_URL='http://IP-หรือโดเมนของเซิร์ฟเวอร์:5000'
python app.py
```

เปิด `http://127.0.0.1:5000` บนเครื่องที่รันเซิร์ฟเวอร์

## บัญชีเริ่มต้น
- ครู: `admin`
- รหัสผ่านเริ่มต้น: `ChangeMe123!`

**เปลี่ยนรหัสผ่านก่อนใช้งานจริง** (ต้นแบบนี้ยังไม่มีหน้าเปลี่ยนรหัสผ่าน/จัดการบัญชีครู) และอย่าเปิดเซิร์ฟเวอร์สู่สาธารณะโดยยังไม่ตั้งค่าให้ปลอดภัย

## นำเข้ารายชื่อนักเรียน
1. สร้างรายวิชาก่อน
2. ไปที่ “นำเข้ารายชื่อนักเรียน Excel” แล้วดาวน์โหลดไฟล์ตัวอย่าง
3. เติมข้อมูลและเลือกไฟล์ `.xlsx` พร้อมเลือกรายวิชา
4. หัวตารางที่จำเป็น: `เลขประจำตัวนักเรียน`, `ชื่อ-นามสกุล`
5. คอลัมน์เพิ่มเติม: `ระดับชั้น`, `ห้อง`, `รหัสผ่าน`
6. หากเว้นรหัสผ่านไว้ ระบบตั้งรหัสผ่านเริ่มต้นเป็นเลขประจำตัวนักเรียน ควรเปลี่ยนหลังเข้าสู่ระบบ

การนำเข้าซ้ำจะอัปเดตชื่อ/ชั้น/ห้อง แต่ไม่รีเซ็ตรหัสผ่านของผู้ใช้เดิม

## ข้อจำกัดสำคัญก่อนใช้งานจริง
- นี่เป็นต้นแบบที่รันได้ ไม่ใช่บริการที่ติดตั้งออนไลน์ให้แล้ว ผู้ใช้ต้องนำไปติดตั้งบนเซิร์ฟเวอร์หรือโฮสติ้งที่รองรับ Python และ HTTPS
- หากต้องการให้นักเรียนสแกนจากคนละเครือข่าย ต้องตั้ง `PUBLIC_BASE_URL` เป็น URL/โดเมนที่เข้าถึงได้จากอุปกรณ์นักเรียน ไม่ใช่ `127.0.0.1`
- ระบบเปลี่ยน token ทุก 5 นาที แต่ QR ไม่สามารถป้องกันการส่งต่อแบบเรียลไทม์ได้ทั้งหมด ควรเพิ่มมาตรการยืนยันตัวตน/ตรวจสอบตำแหน่งตามนโยบายและกฎหมายที่เกี่ยวข้องหากจำเป็น
- การเช็คชื่อออนไลน์ใช้ได้เมื่ออุปกรณ์เชื่อมต่ออินเทอร์เน็ตและเข้าถึงเซิร์ฟเวอร์ได้
- ยังไม่มีการรีเซ็ตรหัสผ่านด้วยตนเอง, SSO/Google, การส่งข้อความแจ้งเตือน, ระบบลาหรือแนบหลักฐาน, การแบ่งสิทธิ์ผู้ดูแลหลายระดับ, สำรองข้อมูลอัตโนมัติ หรือการเชื่อมระบบโรงเรียน
- ระบบคำนวณสถานะ “ขาด” ในรายงานจากผู้ที่ยังไม่มีรายการเช็คชื่อ และการส่งออก Excel จะแสดงผู้ที่ยังไม่มีรายการเป็น “ขาด”; ครูสามารถแก้เป็น “ลา” หรือสถานะอื่นได้
- หากจะใช้ข้อมูลนักเรียนจริง ต้องทำ HTTPS, เปลี่ยนคีย์ลับและรหัสผ่านเริ่มต้น, ใช้ฐานข้อมูล/สำรองข้อมูลที่เหมาะสม, จำกัดสิทธิ์และตรวจสอบการปฏิบัติตาม PDPA

## รันบนเครือข่ายภายในโรงเรียน
กำหนด `PUBLIC_BASE_URL` เป็น IP ภายในของเครื่องเซิร์ฟเวอร์ เช่น `http://192.168.1.20:5000` และอนุญาตพอร์ต 5000 ในไฟร์วอลล์เฉพาะเครือข่ายที่เชื่อถือได้ นักเรียนต้องเชื่อมต่อเครือข่ายที่เข้าถึงเครื่องนั้นได้ หากเปิดใช้งานนอกเครือข่ายควรใช้โดเมนและ HTTPS ผ่าน reverse proxy
